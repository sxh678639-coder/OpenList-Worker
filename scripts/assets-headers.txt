# Cloudflare Workers 静态资源配置（_headers）
#
# 说明：Cloudflare 默认对静态资源返回
#   Cache-Control: public, max-age=0, must-revalidate
# 导致浏览器每次访问都对约 10 个 JS/CSS 资源发起重新验证请求，增加多次 RTT。
# 此文件由 scripts/fetch-frontend.mjs 在构建时复制进 dist/，随 wrangler deploy
# 上传生效（_headers 本身不会被当作静态资源对外服务）。
#
# 注意：Worker 代码里 index.ts 对 /assets/* 的 immutable 设置只有在
# run_worker_first 场景才会执行；默认路由下静态资源由 Cloudflare 直接服务，
# 缓存头完全由本文件控制。

# 带内容哈希的构建产物：文件名不变即内容不变，可永久缓存
/assets/*
  Cache-Control: public, max-age=31536000, immutable

# HTML 入口：必须每次重新验证，避免新版本部署后旧 HTML 引用旧 hash 资源
/
  Cache-Control: no-cache, must-revalidate

/index.html
  Cache-Control: no-cache, must-revalidate
